# Wellness Store Frontend (React + Vite + Tailwind)

Frontend only. Demo data. Shopify to be connected later.

## Run
```
npm install
npm run dev
```
Build: `npm run build`

## Change images
Open `src/data/images.js` and replace each placehold.co link with your own image URL.
Product images are generated by `IMG.product(n, i)`; for real products put your own URLs in `src/data/mockProducts.js` (`images: [...]`).
Brand name / phone / free-shipping threshold: `src/config.js`.

## Routes
/, /collections, /collections/:slug (all-products, new-arrivals, bundles, best-sellers, or a category), /products/:handle,
/search?q=, /cart, /about, /contact, /blog, /blog/:slug, /faq, /shipping-policy, /return-refund-policy,
/privacy-policy, /terms-and-conditions, * (404)

## Connect Shopify later
1. Shopify Admin > Apps > Develop apps > create app > enable **Storefront API** scopes (read products, collections; write/read carts & checkouts). Copy the **Storefront** access token (public one - never the Admin token).
2. Put values in `.env`: `VITE_SHOPIFY_STORE_DOMAIN`, `VITE_SHOPIFY_STOREFRONT_ACCESS_TOKEN`. Restart `npm run dev`.
3. `src/services/shopify.js` already exposes `shopifyFetch(query, variables)`.
4. In `src/services/productService.js` replace each mock function body with a GraphQL query (products, collections, productByHandle, search) and map results to the same product shape used in `mockProducts.js` (id, handle, title, price, compareAtPrice, images[], variants[{id,title,price}], category).
5. In `src/services/cartService.js` replace add/update/remove with `cartCreate`, `cartLinesAdd`, `cartLinesUpdate`, `cartLinesRemove`; store the Shopify `cartId` in localStorage.
6. Replace `cartService.checkout()` to return `cart.checkoutUrl` and `window.location.assign(url)` - Shopify handles payment.
7. UI components stay unchanged.
